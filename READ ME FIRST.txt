========================================
  Yt-dlp Downloader  -  READ ME FIRST
========================================

HOW TO RUN
----------
NEW PC: double-click "Install Yt-dlp Downloader.cmd". Setup downloads the latest
app and all helpers, adds shortcuts, and opens the downloader. No admin needed.
Requires internet and Windows 10/11 on an Intel/AMD 64-bit PC.
Installed location: %LOCALAPPDATA%\Yt-dlp Downloader
Close the downloader and rerun the installer to update. Your data is kept.
The app also checks for updates when opened. Choose Update now or Later.
Menu option 5 updates/repairs the app and all download helpers together.
Unchanged verified helpers are reused. Updates restart the app.
If you have an older app, use its Update option once and then reopen it.
Setup shows downloaded MB while working. FFmpeg is the largest download;
the "Step 3/6 complete" line does not mean its download is stuck at 50%.
If a connection stalls, setup retries or switches the FFmpeg download source.
If setup cannot finish, rerun it later. Error details are saved in:
  %LOCALAPPDATA%\Yt-dlp Downloader\logs\setup-*.log

ALREADY HAVE A PORTABLE COPY:
1. Keep ALL the files in this folder together (don't move just one out).
2. Double-click:  Yt-dlp Downloader.cmd
3. Follow the on-screen menu. Review your choices and destination before starting.
   Choose "Change choices" to edit them, or cancel without starting a download.
   Arrow keys and Enter select options; small terminals use numbered prompts.
4. For several links, choose menu option 2, "Download queue". Add links, then
   start the queue. It runs one at a time. Closing the app clears the queue.
   Ctrl+C stops processing; failed or interrupted items can be retried.


PORTABLE COPIES WITH MISSING HELPERS
----------------------------
The fresh-PC installer includes every helper; no separate setup is needed.
For an older portable copy, the app needs two helpers. If either is missing, it will OFFER TO
INSTALL THEM FOR YOU when you start a download - just answer "Y":

  * Node.js  -> downloaded beside the app, with checksum verification.
               Needed for YouTube. No administrator access is needed.

  * FFmpeg   -> downloaded straight into this folder (about 110 MB, no install).
               Only needed for MP3/AAC audio and best-quality video merges.
               If you skip setup, you return to the main menu.

Library, history, and settings work without installing these helpers.

You don't have to install anything by hand. If for some reason the automatic
setup can't run, the tool tells you exactly what to get and where.


WHERE DO MY DOWNLOADS GO?
-------------------------
Into a "Downloads" folder that appears next to the .cmd, sorted by date.


TROUBLESHOOTING
---------------
- Video details aren't ready? Choose live/playlist handling manually; no wait needed.
- Damaged history? Valid records still display, with a count of skipped rows.
  Your original history file is preserved.
- Setup fails? Check your internet connection and run the installer again.
  If it keeps failing, share the latest setup log from the folder above.
  Node.js, FFmpeg, Python, winget, and PowerShell 7 do not need to be preinstalled.
- A site suddenly stopped working -> open the tool and choose menu option 5,
  "Update / repair app and download helpers".

Enjoy!
