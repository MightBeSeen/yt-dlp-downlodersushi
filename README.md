# Seen's yt-dlp Downloader

Double-click **Seen's yt-dlp Downloader.cmd** and follow the terminal prompts.

It supports MP4, MP3, MKV, AAC, playlists, livestream downloads from the start, daily download folders, and file-size history.

Requires Windows and [FFmpeg](https://ffmpeg.org/) on `PATH`. `yt-dlp.exe` is included.
